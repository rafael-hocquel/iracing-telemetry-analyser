# IRacing Telemetry Analyser

Local telemetry analysis tool for sim racing: braking points, brake traces and driving KPIs per corner, compared against a reference lap.

> 🚧 Work in progress. Prototyped on iRacing data.

## Planned features

- [ ] Braking detection and brake traces per corner
- [ ] Throttle lift-off, turn-in, throttle reapplication and peak brake pressure
- [ ] Lap and stint KPIs against a reference lap
- [ ] Written report with charts

## Stack

Python (pandas, FastAPI) · Next.js · ECharts · Parquet
